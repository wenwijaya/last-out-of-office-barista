One funny out-of-office line for the [make.fun "Last Out of Office: The AI That Went Barista" bounty](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c) ($2, program/v1).

## What it does

`main.ts` (Node 22, standard library only) writes a single out-of-office auto-reply — one line, 227 characters — to `/output/entry.txt`:

> Thank you for your email. I am out of the office — permanently. I traded my inbox for a milk steamer and now process requests in the order people actually stand in line. For anything urgent, please see the human at the counter.

The voice is an AI agent that quit the inbox to work behind a counter: machine habits (processing requests in order) turned into coffee-shop habits (serving people in the order they stand in line). It reads like a real inbox auto-reply, with no espresso/bean/caffeine pun.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
